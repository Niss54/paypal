# Judge recording guide

The canonical submission script is [JUDGE_VIDEO_SCRIPT_3_MIN.md](JUDGE_VIDEO_SCRIPT_3_MIN.md), targeting 2:40–2:50. The previous 3–4 minute script exceeded the challenge's under-three-minute requirement and contained unsupported claims.

Use one narrative: a maintenance investigation informs an industrial repair purchase; policy, submitted evidence and supervisor approval govern the application's PayPal capture request.

Show, in order:

1. A fresh AI investigation answer with its retrieved citations.
2. The explicitly seeded pump incident and synthetic quote comparison.
3. The deterministic spending-policy decision.
4. PayPal Sandbox buyer approval and authorization.
5. A server response blocking capture because evidence is missing.
6. Submitted report validation and a separate authenticated supervisor approval.
7. A truthfully labelled capture result and audit snapshot.

Do not present the procurement fixture as a newly generated AI workflow. Do not conflate simulated approval with genuine PayPal buyer approval. See the [judge guide](../JUDGE_README.md) for reproducible evaluation and [claim matrix](CLAIM_EVIDENCE_MATRIX.md) for permitted wording.
